Membangun sistem monitoring kedatangan truk penyediaan material produksi bagi Dept. PPIC, berkolaborasi dengan *User* dalam desain tampilan yang dibagi dua yaitu: Admin Dashboard, dan Monitoring List.

&nbsp;

Dalam menjaga ke-akuratan data dan ketelitian dalam pengawasan jadwal kedatangan material produksi, perusahaan memiliki ide untuk mengembangkan sebuah aplikasi berbasis web. Saya bersama dengan *Associate* PT JTEKT Indonesia bersama-sama mengembangkan desain web yang kemudian di implementasikan di kantor.

&nbsp;

Akhirnya setiap pengawas dari Dept. PPIC hingga jajaran direksi bisa melakukan kontrol monitoring jadwal dan aktual kedatangan truk menggunakan tampilan **Monitoring List**. Sementara **Admin Dashboard** digunakan oleh Admin dari PPIC untuk mengelola hingga memverifikasi jadwal dan aktual kedatangan truk.
